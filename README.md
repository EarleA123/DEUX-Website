# DEUX-Website

The project is designed to allow students within the cambridgshire city center area to book online for the barbers, the idea is to save time when booking by creating a seamless interaction with the website to ensure a quick booking process. The elemens within the website must be clear and precise whilst also giving off a welcoming vibe. Student discount is clearly visible throughout the website, the promotions tie in with the target audience of students. 

The importance of booking online saves time for students that have limited time to wait inside the store for a haircut and allowing more time for their studies. The booking form needs to be quick to fill out making the booking process more viable that coming in store before booking. A user story of a busy student that does not have time to wait in store for a haircut would benifit from the booking process to save time for their busy lifestlye, the easy booking process would allow the user to book a date and time slot and turn up at that time to get their haircut minimizing time wasted if he was to wait. The second user persona was a shy intovert computing student who found it hard to interact with others. The booking online process would benifit this user as going in store would cause anxiety and other emotions. The online booking process benifits this user allowing them to skip the awkward interactions as much as possible and turn up for his appointment to get his hair cut.
